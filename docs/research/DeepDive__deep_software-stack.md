  - BUT VERIFY THE SINTERING-STRESS FORM FIRST, BEFORE ANY OTHER WORK. NEML2 implements sigma_s = 3*gamma*phi^2/r using void fraction, so the driving force vanishes at full density; the classical Olevsky form uses relative density squared and peaks there. These give qualitatively different late-stage behaviour - exactly the regime that decides whether copper reaches target density. Read Olevsky, Mater. Sci. Eng. R 1998 (DOI 10.1016/s0927-796x(98)00009-6) and Reiterer/Ewsuk/Arguello, JACerS 89(6) 1930-1935 (2006) (DOI 10.1111/j.1551-2916.2006.01041.x) and settle it on paper. If NEML2's form is wrong for your purpose, a corrected variant is about 60 lines of Python because models are now PyTorch modules.
  - PLAN FOR PYTHON, NOT C++. NEML2 v3 defines 190 models as .py files with only a thin C++ dispatch core. Every custom model you write - multi-step binder kinetics, anisotropic sintering viscosity, a copper-specific sintering stress - is a PyTorch module with a schema-declared interface and optional hand-written chain-rule actions, and it inherits the pyzag adjoint calibration path automatically. This changes the required skill set from MOOSE C++ to Python/PyTorch autograd. Staff and train accordingly.
  - SEPARATE THE TWO PHYSICS INTO TWO COMPOSED MODELS SHARING ONE STATE VARIABLE. Debinding = PUMA-style mass-fraction/porosity bookkeeping driving a chemical volumetric Jacobian; sintering = NEML2 GTN/Olevsky poroviscoplasticity driving porosity down. The handover variable is the void/open-pore fraction phi. Keep PUMA's finite-strain multiplicative split, Fe = VolumeAdjustDeformationGradient(F, Jthermal*Jchemical), but add a third INELASTIC densification contribution rather than folding densification into an eigenstrain - otherwise residual stresses will be wrong, because a sintering body is viscous, not elastic.

PUMA's ContractingGeometry with a fitted order of 7.35 (and a calibration script allowing n up to 220) is curve-fitting, not kinetics. An unknown proprietary photopolymer will almost certainly show 2-4 distinct DTG events (network scission, dispersant/plasticiser, residual monomer, char). Build a NEML2 ComposedModel summing N parallel ArrheniusParameter + reaction-model chains with weights summing to one; let N be a model-selection decision driven by the shape of E(alpha); calibrate all of it by pyzag adjoint against multi-rate TGA. The number of holds in the debinding cycle should fall out of the number of kinetic events, not out of a guess.
